## 🌟 Overview

This is the official portfolio and interactive case study platform for **Vinoth Kumar Murugan**, highlighting applied experience across exploratory data analysis (EDA), predictive modeling, business analytics, and user-centered decision systems.

The portfolio is built with **React 19**, **TypeScript**, **Tailwind CSS v4**, **Recharts**, and **Vite**, featuring live interactive simulations for real-world projects rather than static portfolio text.

### 1. Interactive Project Case Studies
- **Sales Analytics on Retail Dataset (July 2025)**:

## 💻 Local Development Setup

To run this repository locally:

### 1. Clone the repository
```bash
git clone https://github.com/<your-username>/vinoth-kumar-murugan-portfolio.git
cd vinoth-kumar-murugan-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
npm run build
```
The optimized production bundle will be generated in the `dist/` directory.

### 5. Preview production build
```bash
npm run preview
```

### 6. Type-check / Linting
```bash
npm run lint
```
